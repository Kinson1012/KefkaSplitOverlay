### Kefka P4Overlay for PC
FF14 絕妖星P4判定輔助工具

## 使用方式
1. 點擊右側Release下載 Kefka P4.exe
2. 直接執行，無需安裝任何額外軟體
3. 建議 FF14 使用「無邊框視窗」模式，讓 overlay 可以顯示在遊戲上方
4. 右上齒輪內可設定，三角形可最小化視窗
5. 設定內可調整模式、語言、透明度、左右翻轉、解除鎖定視窗後可拖動視窗邊緣調整視窗大小....

## 功能
流程型: 按鈕以詠唱順序排列，小抄以發動順序排列
跟跑人: 把內容簡化到只有炸彈、分攤分散、視線(有call或跟跑的時候用的)
Beta： 舊的版本移植
支援中文 / 日本語 / English

## 注意事項
首次執行可能出現 Windows SmartScreen 警告
點「更多資訊」→「仍要執行」即可
這是正常現象，程式本身不含任何惡意程式碼

### Kefka P4Overlay for PC
A jassistance overlay for FF14 DMU kefka P4

## How to Use
1. Click Release on the right and download latest Kefka P4.exe.
2. Run it directly — no installation or additional software required
3. Recommended: set FF14 to Borderless Window mode so the overlay appears on top of the game
4. Click the gear icon in the top-right to open the settings. Click the triangle icon to minimize the window.
5. In the settings, you can change the mode, language, opacity, flip, and unlock window resizing to resize the window by dragging its edges.

## Features
Flow: Buttons are arranged in cast order, while the notes are displayed in execution order
Pikmin: Simplified view with only Bombs, Stack/Spread and Gaze mechanics (recommended when following callouts or Pikmin)
Beta: Old ver.
Supports 中文 / 日本語 / English

## Notes
Windows SmartScreen may show a warning on first launch
Click "More info" → "Run anyway" to proceed
This is normal behavior for unsigned applications — the program contains no malicious code

### Kefka P4 Overlay for PC
FF14 絶妖星乱舞 P4 判定支援ツール

## 使い方
1. 右側のReleaseクリック　Kefka P4.exe をダウンロード
2. インストール不要。そのまま実行できます
3. FF14 は「ボーダーレスウィンドウ」モードでの使用を推奨します（オーバーレイをゲーム上に表示できます）
4. 右上の歯車から設定できます、三角アイコンでウィンドウを最小化できます。
5. 設定内ではモード、言語、透明度、左右反転を調整でき、ウィンドウのロックを解除すると、ウィンドウの端をドラッグしてサイズを変更できます

## 機能
フロー形式：ボタンは詠唱順に並び、小抄は発動順に表示されます
ピクミン: 爆弾、頭割り／分散、視線のみを表示する簡易版（ピクミンやコールがある場合に使用）
Beta モード： 旧バージョンを移植したモード
日本語 / English / 中文 対応

## 注意事項
初回起動時に Windows SmartScreen の警告が表示される場合があります
「詳細情報」→「実行」を選択すると起動できます
署名のないアプリのため表示されるものであり、悪意のあるプログラムではありません
